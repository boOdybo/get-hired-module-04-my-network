# GET HIRED — Module 04: MY NETWORK

[فتح العرض التفاعلي](https://boodybo.github.io/get-hired-module-04-my-network/)

## Main presentation
`docs/index.html`

Open the standalone HTML file in a modern browser. Core slides, navigation, diagrams, and study notes are self-contained.

## Included files
- `Source_Mapping_and_Coverage.md` — source traceability, activity fidelity, deliverable attribution, tool caveats, and official references.
- `Trainer_Guide.md` — session pacing, demo workflow, activity facilitation, assessment evidence, and fallbacks.
- `Student_Workbook_AR.md` — profile worksheet, Headline/About drafting, Grammarly review, connection request, opportunity search, and privacy review.
- `Slide_Storyboard.md` — slide-by-slide instructional sequence and purpose.
- `Activity_Brief_LinkedIn_Makeover.md` — full activity brief for the official source activity.
- `QA_Report.md` — build checks, source coverage, test status, and known limitations.

## Presentation modes
- **العرض:** uncluttered slide content.
- **مذاكرة الطالب:** expanded explanations.
- **المدرّب:** trainer notes and facilitation guidance.

## Navigation
- Next: Right Arrow / Page Down / Space
- Previous: Left Arrow / Page Up
- First / Last: Home / End
- Fullscreen: F or the on-screen button
- Overview: فهرس

## Interactive elements
- Copy buttons for prompts.
- Editable profile-input workspace that generates a LinkedIn Headline/About prompt locally in the browser.
- Quiz feedback.

The profile builder does not send data anywhere automatically. Review and anonymise inputs before copying them into an external AI tool.

## Important
The fictional graduate profile and sample Headline/About text are teaching examples only. Students must use their own truthful skills, projects, and career direction. Grammarly compatibility with LinkedIn text fields may vary; use Grammarly Editor or a manual review checklist if the browser extension is not supported.
