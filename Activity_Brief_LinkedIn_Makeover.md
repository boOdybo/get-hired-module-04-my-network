# Module 04 — Activity Brief
## Official activity: LinkedIn Makeover

**Source:** `04. Networking.pdf`, page 2, AI TOOLS SESSION.

| Field | Detail |
|---|---|
| Activity title | LinkedIn Makeover |
| Objective | Produce and improve a LinkedIn Headline and About section using ChatGPT, then manually personalise and review the drafts. |
| Scenario | A fresh graduate is preparing a LinkedIn profile for a target sector and wants to communicate real skills and evidence clearly. |
| Suggested time | 30 minutes (trainer allocation within the 120-minute session; source does not specify activity minutes). |
| Format | Individual drafting; trainer and peer review; group/peer vote. |
| Tools | LinkedIn, ChatGPT, Grammarly where available. No paid plan assumed. |
| Required inputs | Field/degree, target sector/role, demonstrated skills, one real project or experience, professional interests. |
| Prompt | Preserve the source Headline prompt: `Write a LinkedIn headline for a fresh graduate in [field] targeting [sector]. Make it specific and value-focused.` Use the additional About prompt in the deck as an instructional template. |

## Student instructions

1. Draft a Headline and About section using the ChatGPT prompts.
2. Check that every skill, experience, and achievement is accurate.
3. Improve the drafts manually with personal details.
4. Use Grammarly to review clarity and professionalism if available; otherwise use the workbook checklist.
5. Share the revised drafts with the trainer and a peer for feedback.
6. The best About section is read aloud and receives peer-vote XP, following the programme organiser's XP rules.

## Trainer facilitation

- Demonstrate with a fictional graduate profile, clearly labelled as fictional.
- Do not ask students to display private profile settings or personal contact information.
- Remind students that Grammarly may not be supported in every LinkedIn field.
- Require specific feedback: one strength and one actionable improvement.
- Do not invent an XP amount or replace the programme's scoring rules.

## Expected output

- Original Headline draft.
- AI-assisted Headline alternatives.
- Manually revised Headline.
- About section draft and manually revised version.
- Short review note explaining what was accepted, changed, or rejected.

## Submission

A digital or printed worksheet, document, or PDF. Publishing the profile publicly during the session is not required.

## Assessment criteria (trainer-designed guidance)

- Truthfulness: every claim is supportable.
- Specificity: field and skills are clear.
- Relevance: content aligns with the target sector or role.
- Clarity: language is natural and professional.
- Personal voice: text sounds like the student, not a generic template.

These criteria are not an official XP rubric in the source.

## Debrief questions

1. Which AI suggestion improved your profile without changing the facts?
2. Which suggestion did you reject, and why?
3. What makes an About section sound authentic rather than generic?

## Fallback

If a student cannot access LinkedIn or ChatGPT, use the slide's fictional profile and prompt worksheet. If Grammarly is unavailable in the target field, use Grammarly Editor or the manual review checklist.
